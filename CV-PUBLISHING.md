# Website CV publication

The CV is generated by GitHub Actions in the private `jrudoler/RudolerCV` repo.
The public `cv-artifacts` branch of this website repository contains the PDF, public publication data, and
an automatic deployment workflow. Do not edit that branch manually.

Website deployments always build this repository's `master` branch and then
install `RudolerCV.pdf` from `cv-artifacts` at `/files/RudolerCV.pdf`. This keeps
existing CV links working and prevents an old source PDF from replacing it.
There is deliberately no `files/RudolerCV.pdf` on `master`; do not copy one here.
If the generated PDF is missing, deployment fails instead of publishing a stale CV.

Push website changes to `master` as usual. To update the CV, commit and push its
source and Zotero-exported bibliography in the CV repository. A successful CV build
updates `cv-artifacts`, which triggers a fresh website deployment. Zotero does not
commit or push automatically. The publication list is exported from that same bibliography as `publications.json`.
The research narrative is maintained separately; see PUBLICATIONS.md for local
previews and website topic/featured settings.

The artifact branch includes `.github/workflows/pages.yml` so its PDF updates can
trigger Actions. The CV publisher refreshes that workflow from website `master`.
